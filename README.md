# HealthSethu360
### Connected Care. Smarter Hospitals. Healthier Lives.

**HealthSethu360** is an enterprise-grade multi-branch hospital management and healthcare SaaS platform. It connects hospital administrators, doctors, nurses, receptionists, pharmacists, billing teams, and patients through one unified digital healthcare ecosystem.

---

## Technology Stack

- **Frontend**: React.js 18, React Router, Axios, Lucide React, CSS3 Design Tokens
- **Backend**: Java 17, Spring Boot 3.3.x, Spring MVC, Spring Security 6.x, Spring JDBC (`JdbcTemplate`), Bean Validation
- **Database**: MySQL Community Server 8.0 with normalized schema, constraints, indexes
- **JSP/Servlet Module**: Dedicated sub-module for enterprise servlet demonstrations

---
