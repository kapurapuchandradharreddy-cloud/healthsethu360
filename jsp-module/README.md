# HealthSethu360 — JSP & Servlet Module

This module provides a standalone, dedicated Java EE Servlet and JSP demonstration submodule for HealthSethu360.

Per the architectural guidelines:
- React.js serves as the primary modern SPA frontend for all clinical, operational, and patient workflows.
- This module demonstrates pure Java Servlet and JSP concepts (e.g. server-side filters, session management, and server-rendered status pages) without corrupting or duplicating the primary React application.
